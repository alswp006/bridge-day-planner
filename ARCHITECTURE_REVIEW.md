# Architecture Review
Generated: 2026-10-03T16:32:10.237Z
Score: 66/100

## Summary
The codebase has a clear layering: pages call components, components call lib, and lib has no upward imports. I found no circular dependencies. The structure is a scaffold template with a small bridge-day calculator on top, so there is a lot of unused template code, the same logic is repeated in several places, and import and storage conventions are inconsistent. Production code (`PageShell.pick`, `Card.SPACING_TYPE`) is also bent to survive test-mocking quirks.
