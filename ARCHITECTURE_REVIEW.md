# Architecture Review
Generated: 2026-10-04T16:38:39.680Z
Score: 66/100

## Summary
The codebase has a sensible layering: domain logic in lib/, shared UI in components/, and screens in pages/. The SDK-guard wrappers in analytics, share and review are thoughtfully isolated. Its weaknesses are duplicated helpers and SDK-guard patterns, inconsistent storage and haptic access, an unused contract.ts file, and a Result page that holds domain and persistence logic that belongs in lib/. There are no circular dependencies, but several components and utilities look unused, and some production code is bent around test-mocking concerns.
